# 試行台帳

同じデータに仮説をいくつも当てると、どれかが偶然「合格」する。
それを防ぐため、試行はすべてここに番号順で記録し、封印期間(2024-01-01〜)の合格基準は
**その時点までの累計試行数 N で片側 5%/N(ボンフェローニ補正)** に厳しくする。
