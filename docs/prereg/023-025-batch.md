# 事前登録 023〜025(一括): 仮想通貨のファンディングレート・キャリー

登録日: 2026-09-28(いずれの仮説もデータを取得する前に固定)
補正ルール: LEDGER.md の改訂版。現在 K=5。

## 仕組み
現物を 1 単位買い、同じ量の USDT 建て無期限先物を売る(価格変動をほぼ相殺)。
ファンディングレートが正なら、先物の売り手が 8 時間ごとに受け取る。予想ではなく仕組みで生まれる収入。
リスク: 取引所の破綻・出金停止(バックテストでは評価できない)、ファンディングが負になる期間、急騰時の証拠金不足。

## データ(Binance の公開アーカイブ data.binance.vision)
- ファンディングレート: futures/um の fundingRate(月次ファイル)。
- 価格: 現物(spot)と USDT 先物(futures/um)の日足 klines の終値(UTC 00:00 区切り)。

## 損益の測り方(共通)
- 必要資本 = 想定元本 × 1.5(現物 1.0 + 先物の証拠金 0.5)。証拠金の余りは利息なし(保守的)。
  日次で現物と先物口座の資金を調整して清算を避ける前提。その振替は無料とする。
  期間中の先物の最大日次上昇率を記録し、50% を超える日があれば前提が崩れたとして報告する。
- 日次の損益(想定元本比) = その日に確定したファンディングの合計 + (現物の日次リターン − 先物の日次リターン)。
- 売買手数料: 建てるとき・外すときに、現物 0.10% + 先物 0.05%(ともにテイカー)を想定元本に対してかける。
- 月次リターン(資本比) = その月の日次損益の合計 / 1.5。
- **判定は米国 T-bill(DTB3)を差し引いた月次超過リターン**で行う。現金を置いておくだけで得られる利回りを超えなければ意味がない。

## 仮説
- 023: BTCUSDT に常時ポジションを持つ(最初に 1 回建て、期間の最後に外す)。
- 024: ETHUSDT に常時ポジションを持つ。
- 025: 条件付きの複数銘柄。対象は 2020-01-01 時点で Binance の USDT 先物に上場していた銘柄のうち、
  データが揃うもの(生存者バイアスを避けるため、その後の上場廃止も含めて固定。廃止されたら最終日に外す)。
  毎日 00:00 UTC に、直近 7 日のファンディングの平均が 8 時間あたり 0.01%(年率約 11%)を超える銘柄を持ち、
  下回ったら外す。資本は持っている銘柄に均等に割り当てる(持つ銘柄が無い日は 0)。建て外しのたびに手数料。

## 修正記録(データ取得後・損益を計算する前、2026-09-28)
- アーカイブのファンディングデータは 2020-01 から。2020-01-01 時点の上場は BTC/ETH/BCH の 3 銘柄だけで分散にならない。
  → 025 の対象を「2020-03-31 までにファンディングデータが始まった銘柄」に変更(上場日だけで決まり、その後の値動きは見ていない)。
  24 銘柄: BTC ETH BCH XRP EOS LTC TRX ETC LINK ADA XLM XMR DASH XTZ ZEC ATOM BNB ONT IOTA BAT VET NEO IOST QTUM。
  各銘柄は、その日にファンディング・現物・先物のデータが揃っている日だけ対象にする(現物の上場廃止などで欠けたら外す)。

## 期間と合格基準
- 開発: 2020-01〜2023-12(48 か月)。封印: 2024-01〜2026-08。
- 開発の合格基準: 月次超過リターンの平均 > 0 かつ t ≥ 2.0、暦年 4 年のうち 3 年以上でプラス。
- 封印の合格基準: 平均 > 0 かつ t ≥ z(1 − 0.05/K)(番号順に開ける。023 → K=6 で t ≥ 2.39、以降 +1)、
  2024 年と 2025 年の両方でプラス。
- 参考: 年率リターン、最大ドローダウン、ファンディングが負だった日の割合も記録する。
