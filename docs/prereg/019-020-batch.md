# 事前登録 019〜020(一括): 月末月初効果を長期の日足で検証

登録日: 2026-09-28(この 2 本の長期データの結果を見る前に固定)
補正ルール: LEDGER.md の改訂版。現在 K=2。

## 経緯(正直な記録)
015/016 で、Exness の 2020〜2023 年データでは月末月初効果が raw +35〜41bp と大きいのに
取引回数不足で有意にならなかった。その結果を見たうえで、長期データでの検証を計画している。
新しい封印期間(2010 年〜)の一部(2020〜2023)を 015/016 で既に見ていることになる。
その分だけ封印の独立性は弱いが、基準は緩めない。

## 共通ルール
- データ: FRED の日次終値(価格指数、配当は含まない)。取引日はデータに値がある日。
- 月の最終取引日の 1 つ前の日の終値で買い、翌月の第 3 取引日の終値で売る。
- コスト: 往復 5bp(スプレッド + スリッページ)。
  保有コスト(CFD の金利調整) = (その国の短期金利 + 2.5%) × 暦日数 / 365。
  - 日本: コールレート(IRSTCI01JPM156N、1985 年〜)、それ以前は公定歩合(INTDSRJPM193N)。月次。
  - 米国: 3 か月 T-bill(DTB3、日次)。
- 損切り・利確なし。
