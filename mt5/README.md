# MT5 EA(デモ口座での前向きテスト用)

## GotobiFade.mq5(事前登録 002)
五十日の 09:55 JST に USDJPY を売り、11:00 JST に買い戻す。月に 6 回ほど取引する。

### 入れ方
1. Exness でデモ口座(MT5)を作る。
2. MT5 を起動し、メニューの「ファイル」→「データフォルダを開く」を選ぶ。
3. 開いたフォルダの `MQL5\Experts` に `GotobiFade.mq5` をコピーする。
4. MT5 のナビゲーターで「エキスパートアドバイザ」を右クリックして「更新」を選ぶ。
   `GotobiFade` をダブルクリックすると MetaEditor が開くので、「コンパイル」を押す。
5. USDJPY のチャート(時間足は何でもよい)に `GotobiFade` をドラッグする。
   - 「アルゴリズム取引を許可」にチェックを入れる。
   - ツールバーの「アルゴ取引」ボタンを緑(オン)にする。
6. 「エキスパート」タブに「GotobiFade 開始: …」と出れば動いている。
   その行の「今日は五十日=はい/いいえ」が正しいかを一度確認する。

Exness の Standard 口座では銘柄名が `USDJPYm` になるが、そのまま動く。

### 注意
- PC(または VPS)と MT5 は、五十日の 09:50〜11:05 JST に起動している必要がある。
- PC の時計を「自動で時刻を合わせる」にしておく(EA は PC の時計で JST を計算している)。
- リアル口座では動かない設定になっている(`AllowRealAccount=false`)。
- 取引の記録は `MQL5\Files\GotobiFade_log.csv` に残る。数か月たったら、このファイルを
  共有してもらえれば、バックテストとのズレ(スプレッド・約定価格)を確認する。
